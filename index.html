关于项目

这是什么？

一场完全免费的芯片设计之旅，
从代码开始，到一颗真正的芯片结束。

"一生一芯"是2019年由中国科学院大学联合中科院计算技术研究所启动的公益性芯片培养项目，对标国际 MOSIS 项目。不需要你有深厚的专业背景——只要你对"计算机到底是怎么跑起来的"感到好奇，就能在这里找到答案。

项目规模

全国规模最大的芯片人才社区

20000+

1300+

培养学生人数

项目用"开源开放、独立解决问题、软硬件全栈、芯片全链条"的理念培养人才。学员毕业后进入国内芯片企业或高校课题组，投身处理器芯片、计算机系统、系统软件等方向，攻关卡脖子领域。

全栈流程

从软件到芯片，一条完整链路

这不是只学写代码，也不是只学画版图。你会经历从 IP 设计、SoC 集成、EDA 工具，到掩模制造、再到基础软件适配和应用开发的完整链条。

芯片设计 → 芯片制造 → 软件开发，前后端全链条贯通

学习路径

你会经历什么

三个阶段，一步步从理论走向实物。

1

CPU 设计

用 Verilog 从零写出一个能跑程序的处理器核心，从3条指令的数列求和开始

2

操作系统

在你自己设计的 CPU 上跑起 RT-Thread、Linux，让芯片真正有用

3

芯片版图与流片

完成物理版图设计，提交工厂流片，把你的设计变成拿在手里的芯片

从 F 阶段（数列求和）到 S 阶段（乱序超标量），覆盖大一上到研究生

你将收获

能做到这些

跑起来

让你的芯片跑起超级玛丽

在自己设计的处理器上运行经典游戏。从 Verilog 代码开始，搭建流水线、实现指令集，最终在 FPGA 上验证你的 CPU 能加载并运行 NES 游戏。

流片

拿到一颗真实的芯片

优秀学员将参与流片，把你的设计变成物理实物拿在手里。完成从 RTL 到 GDSII 的全流程，几个月后收到一颗刻着你名字的芯片。

认证

官方认证与学习证明

完成学习路径的学员将获得由"一生一芯"项目组颁发的等级认证证书，包含能力水平认证等级和助教评语，为简历添上硬核一笔。

毕业收获

你将拿到什么

完成学习路径后：亲手设计的流片芯片实物、开发板卡、以及由"一生一芯"项目组颁发的等级认证证书。
