关于项目

这是什么？

一场完全免费的芯片设计之旅，
从代码开始，到一颗真正的芯片结束。

一生一芯是由中国科学院大学发起的公益性芯片培养项目。不需要你有深厚的专业背景，只要你对"计算机到底是怎么跑起来的"感到好奇，就能在这里找到答案。

学习路径

你会经历什么

三个阶段，一步步从理论走向实物。

1

CPU 设计

用 Verilog 从零写出一个能跑程序的处理器核心

2

操作系统

在你自己设计的 CPU 上，跑起一个操作系统

3

芯片版图与流片

完成物理版图设计，最终把你的芯片送到工厂流片

你将收获

能做到这些

让你的芯片跑起超级玛丽

在自己设计的处理器上运行经典游戏，这不是模拟器，是你亲手写的芯片在跑。从 Verilog 代码开始，搭建流水线、实现指令集，最终在 FPGA 上验证你的 CPU 能加载并运行 NES 游戏。

拿到一颗真实的芯片

优秀学员将参与流片，把你的设计变成物理实物，拿在手里。完成从 RTL 到 GDSII 的全流程，通过 DRC/LVS 验证后提交到台积电或中芯国际流片，几个月后你会收到一颗刻着你名字的芯片。

官方认证与学习证明

完成学习路径的学员将获得项目官方认证，为你的简历添上硬核一笔。由"一生一芯"项目组颁发的结课证明，以及在 RISC-V 生态中的社区认可。
